## 🔍 Types de sélecteurs expliqués

### 1. Sélecteurs par ID
```css
#readcontent        /* Élément avec id="readcontent" */
#chapter-content    /* Élément avec id="chapter-content" */
#main-content      /* Élément avec id="main-content" */
```

### 2. Sélecteurs par classe simple
```css
.content           /* Élément avec class="content" */
.entry-content     /* Élément avec class="entry-content" */
.post-content      /* Élément avec class="post-content" */
```

### 3. Sélecteurs par classe multiple (pour classes complexes)
```css
.td_block_wrap.tdb_single_content  /* Élément avec ces deux classes */
.tdb-single-content.tdb-block-inner  /* Élément avec ces deux classes */
.entry-content.post-content     /* Élément avec ces deux classes */
```

### 4. Sélecteurs par attribut
```css
[aria-label="content"]           /* Attribut exact */
[aria-label*="content"]          /* Attribut contenant "content" */
[role="main"]                     /* Rôle principal */
[data-content="chapter"]          /* Attribut data personnalisé */
```

## 📝 Notes importantes

1. **Séparateur** : Utilisez des virgules pour séparer les sélecteurs
2. **Ordre** : Les sélecteurs sont testés dans l'ordre
3. **Priorité** : Mettez les sélecteurs les plus probables en premier
4. **Détection automatique** : Si aucun ne fonctionne, FetchNovel essaie automatiquement
5. **Tests** : Commencez avec 1-2 chapitres pour tester les sélecteurs

---

**Conseil** : Utilisez le sélecteur "Expert" pour une compatibilité maximale avec la plupart des sites de novels.
