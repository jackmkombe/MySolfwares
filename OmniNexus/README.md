# 🌐 OmniNexus Manager PRO

Bienvenue dans votre nouveau gestionnaire de collections multimédias intelligent.

## 🚀 Démarrage Rapide

1. Allez dans le dossier `OmniNexus`.
2. Lancez `main.py` (ou utilisez `build_omni.bat` pour créer l'EXE).
3. Cliquez sur **"+ Nouvelle Bibliothèque"**.
4. Configurez vos dossiers de Films, Animés ou Jeux.
5. Allez dans **"Paramètres"** pour ajouter vos clés API (TMDB/RAWG) si besoin.
6. Cliquez sur **"Synchroniser"** et laissez l'IA travailler !

## ✨ Fonctionnalités

- **Nettoyage Automatique** : Identifie les titres même avec des tags de release (1080p, x264, etc.).
- **Fetch Intelligent** : Récupère posters, synopsis, notes et dates via APIs mondiales.
- **Multimédia Total** : Support dédié pour Films, Séries, Animés (Jikan) et Jeux PC (RAWG).
- **Interface Premium** : Design sombre moderne, fluide et réactif.
- **Persistance SQLite** : Votre collection est sauvegardée localement, instantanée au chargement.

## 🛠️ Build & Distribution

Pour générer l'exécutable autonome :

- Lancez simplement `build_omni.bat`.
- L'exécutable final sera généré dans `OmniNexus\dist\OmniNexus_Manager.exe`.
