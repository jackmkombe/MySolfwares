# 💎 MediaNexus Ultra

Bienvenue dans l'élite de la gestion multimédia. **MediaNexus Ultra** est conçu pour les collectionneurs exigeants.

## 🚀 Démarrage Rapide

1. Allez dans le dossier `MediaNexus_Ultra`.
2. Lancez `main.py` pour une exécution instantanée.
3. Créez une bibliothèque (Films, Animés ou Jeux).
4. Synchronisez votre dossier local.

## ✨ Caractéristiques Ultra

- **Moteur Abyss UI** : Interface sombre, fluide et réactive basée sur CustomTkinter.
- **Smart Matching** : Algorithme de nettoyage de noms et calcul de similarité.
- **SQLite Core** : Base de données robuste pour des milliers d'items.
- **Cache Intelligent** : Posters et métadonnées stockés localement.
